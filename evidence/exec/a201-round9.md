## 3. 双方都漏掉的：S22 引用成组错误（我本轮发现）

### 症状

S22 的症状是「**失败路径**返回 `kOk` 但不置 `closed_`」。批 0 后：

```
t:431  if (st == SEC_E_OK || st == SEC_I_CONTINUE_NEEDED) {
t:432      closed_ = true;
t:433      return MakeError(Status::kOk, st, "");
t:434  }
t:435  return MakeError(Status::kOk, st, "shutdown best effort");   <- S22 就是这一行
```

**S22 的修复点是 `:435`，不是 `:433`。** `:433` 是成功分支的返回，不置 `closed_` 是对的。

### 文档里有 6 处写错

| doc | 原文 | 应为 |
|---|---|---|
| 2083 | 实际 `:429` 是 `if`，赋值在 `:430`，失败路径 `:433` | `:431` / `:432` / `:435` |
| 2083 | 「仅在 `:429` 的成功分支」 | `:431` |
| 2091 | `:430`（赋值）、`:433`（失败路径） | `:432` / `:435` |
| 2091 | `:433` 改为 `closed_ = true; ...` | `:435` |
| 2464 | `src/net/tls_schannel.cpp:433`（锚点 `return ... "";`）(S22) | `:435`（锚点 `... best effort`） |
| 3065 | 「S22 的修复点在 `...:433`」 | `:435` |
| 3122 | S22 变异：`:433` 恢复为不置 `closed_` | `:435` |
| 3169 | ① `:433` 置 `closed_=true` | `:435` |

### 为什么门禁看不见

`:433` 是**裸引用**（无锚点从句），落在 `noanchor_other` 计数里，不参与 WRONGLINE。
**且 `:433` 本身在文件里存在**（是成功分支的返回），所以「锚点存在」类判据也放行。

### 为什么这是最危险的一类

`:433` 和 `:435` **都返回 `kOk`**，只有 `:435` 不置 `closed_`。
执行 AI 按 `:433` 改（在成功分支上加 `closed_ = true`）会：
1. 改错位置（成功分支本来就置了）；
2. 真正的缺陷（`:435` 失败路径）仍然存在；
3. 而红证用例 `shutdown_failure_still_marks_closed` 会**通过**——因为成功分支本来就会置。

**这是一个「改错地方也能让测试变绿」的引用错误。**

## 4. 门禁 v10：两条新规则

### I3 区间首片段必须在 `cur[ca]`

v9 的 `range_matches` 对单片段锚点用的是「在区间内任意位置出现」：

```python
if len(parts) == 1:
    return any(parts[0] in s for s in src[ca - 1:cb])
```

**这等于没有起点约束。** 甲、乙各自独立证明：区间整体 -2、锚点在中间 → PASS。

v10：

```python
first = raw[0]
last = raw[-1] if len(raw) > 1 else None
if first not in src[ca - 1]:
    return False
```

### I4 末片段 `}` 用大括号配平

以 `}` 收尾的区间锚点（`` A .. `}` ``），末片段是 `}`，文本到处都有，不能靠文本判定。

v10 改为结构性验证：`ca..cb-1` 的深度必须是 0 或 1，且 `cur[cb]` 必须把它带回 0。

```
t:101-201 -> PASS   (depth 0->1 at 101, back to 0 at 201)
t:371-384 -> PASS
t:99-199  -> FAIL   (depth=2，多了没闭合的块)
t:101-199 -> FAIL   (depth=2)
t:371-386 -> FAIL   (cb 不是闭合行)
```

### I5 `A .. B` 声明必须有两个可用片段

乙发现：`split_anchor` 的 `len(p) >= 6` 过滤会把 `}` 丢掉，
`sig .. }` 退化成单片段，起点约束消失。

v10 保留 `raw`（过滤前），并用 `raw[0]` / `raw[-1]` 判边界。
**退化不再是静默的**——`}` 作为末片段会走 I4 的配平检查。
