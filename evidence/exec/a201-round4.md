### 5.3 第三次：章节边界硬编码

加 `SECTIONS = {'17': (2071, 2837), ...}` 后绿了，但**边界本身也是硬编码**。
我在 §19 内插入 5 行，§20 及之后全部后移 → 边界失效。

**最终方案**：从 `## N.` 标题**动态计算**章节边界。

```python
_HEAD = re.compile(r'^##\s+(\d+)\.')
_starts = [(int(m.group(1)), i) for i, l in enumerate(L) if (m := _HEAD.match(l))]
for k, (num, start) in enumerate(_starts):
    end = _starts[k + 1][1] - 1 if k + 1 < len(_starts) else len(L) - 1
    SECTIONS[str(num)] = (start + 1, end + 1)
```
