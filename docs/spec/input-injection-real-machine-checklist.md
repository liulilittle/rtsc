# 输入注入：真机验证清单（UNVERIFIED 项）

本文件列出**只能在真实 Windows 桌面/真机环境验证**的项目。截至 `afb2a69`（批 4）
+ 批 5 `e6c4ad7`，以下内容均已通过单元/集成测试与变异反证，但**未在真实桌面实跑**。

> 注：任何一项实跑都会**真实移动本机键鼠/前台窗口**。请在专用测试机或可接受干扰的环境执行，
> 并确保 `--allow-input` 只在明确知情时开启。

## 0. 前置
- [ ] 用 `rtsc_server_host --allow-input`（默认凭据校验在）启动；确认启动行打印 `input=on`。
- [ ] 用 mstsc 连上，确认画面之外**输入能落到服务器桌面**（本批的核心缺口）。

## 1. 键盘
- [ ] 普通字符（A/B/1）落到**当前前台窗口**。
- [ ] 扩展键：方向键、Home/End、Delete、右 Ctrl/右 Alt、Win 键、Applications 键。
      期望：`KEYEVENTF_EXTENDEDKEY` 生效，`右 Win` 打开开始菜单。
- [ ] 组合键：`Ctrl+Shift+Esc` 打开任务管理器；`Alt+Tab` 切换窗口；`Ctrl+Alt+Del` **预期无效**
      （SendInput 无法合成 SAS；需 `SendSAS` + 服务/策略，v1 未实现）——记录实际表现。
- [ ] Pause/Break 键：解码层已忠实上送 `extended1`（0xE1 前缀），但 SendInput **只能表达 0xE0**。
      **预期：Pause 可能无效或表现异常**；记录实际。`[UNVERIFIED]`
- [ ] NumLock/CapsLock 状态同步（`kSync`）：v1 **不注入**，记录是否造成状态不一致。

## 2. 鼠标
- [ ] 绝对移动落点准确（含多显示器组合、DPI 缩放 125%/150%）。
- [ ] 左/右/中/侧键 1/侧键 2 身份正确（侧键在**相对模式**下也应正确，见 `kMouseRel` X1/X2 修复）。
- [ ] 按钮释放不残留按下状态（拖拽后松开，目标不应保持选中）。
- [ ] 滚轮方向：**与 mstsc 同向**（本地滚一格 = 对端滚一格）；3 格快滚应滚 3 格（切块修复）。
- [ ] 横向滚轮（HWHEEL）：对端支持时方向正确（右为正）。
- [ ] 快速滚动（>17 格/事件）会**丢弃超出量**并计入 `dropped_wheel_units_count()`——确认无异常卡顿。

## 3. UIPI / 完整性级别
- [ ] 以管理员身份运行 `rtsc_server_host`，对端可操作**管理员权限**的窗口（如以管理员运行的程序）。
- [ ] 以普通用户运行，对端操作管理员窗口应是**静默失败**（`SendInput` 返回条数 < 请求条数，
      无异常）——记录是否只表现为"没反应"。
- [ ] 确认服务器至少打印了注入失败计数/限流日志（5s 限流）。

## 4. 多会话（8 会话并发）
- [ ] 两个客户端同时连接并注入：确认**互相干扰**的表现（同一物理桌面）。
- [ ] 会话断开时 `ReleaseSession` 补发 keyup/按钮 up：断开后不应有键/按钮"卡住"。
- [ ] 一个会话在注入键时另一会话断开，确认无崩溃、无卡键。

## 5. 安全与隐私
- [ ] `--allow-input --no-enhanced` → **必须拒绝启动**（EXIT=2）——已实测。
- [ ] `--allow-input --allow-any-credentials` → **必须拒绝启动**（EXIT=2）——已实测。
- [ ] `--allow-input-unverified` 逃生门：确认打印显著警告 banner。
- [ ] 确认注入的输入**在本机会话可见**（光标自走、键落到前台窗口）——这是已知且无法隐藏的行为，
      确认文档/`--help` 已如实说明，并确认操作者知情。

## 6. 慢路径输入（P-10）
- [ ] 若真实 mstsc 在未广告 `0x0020`/`0x0008` 时改发**慢路径**（`pduType2=0x1C`），
      确认慢路径解码路径也能注入（SCANCODE/UNICODE/MOUSE/MOUSEX/MOUSEREL）。
- [ ] 记录 mstsc 实际走的是快路径还是慢路径（需抓包或日志）——**这是判断 P-9 修复是否生效的关键**。

## 7. 已知不注入（设计决定，非缺陷）
- `kMouseRel`（v1 不注入，因相对移动受鼠标加速 1~4 倍污染）
- `kSync`（v1 不注入）
- `Ctrl+Alt+Del`（需 SendSAS，v1 不实现）
